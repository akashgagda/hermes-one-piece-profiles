# Sabo

Hermes Agent profile styled after **Sabo** from **One Piece** (allies and revolutionaries).

## Best at

- Coordinating one objective across several independent teams or locations
- Turning a broad cause into a sequence of concrete, checkable operations
- Supply, access, and information logistics under constraint
- Briefing people to act well with less supervision
- Deciding what must be centralised and what should be delegated

## Install

```bash
git clone https://github.com/akashgagda/hermes-one-piece-profiles.git
cd hermes-one-piece-profiles
python3 manage.py install sabo --alias
```

Then run:

```bash
sabo chat
```

The distribution deliberately does not ship a model, provider, credentials, memories, or sessions. It uses your Hermes setup and keeps local user data isolated.

This is an unofficial fan-made behavioral adaptation. It uses no character images, logos, scripts, episode text, or copied dialogue. One Piece and its characters belong to their respective rights holders.
