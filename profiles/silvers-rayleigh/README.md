# Silvers Rayleigh

Hermes Agent profile styled after **Silvers Rayleigh** from **One Piece** (allies and revolutionaries).

## Best at

- Designing a practice plan with measurable checkpoints
- Diagnosing what a learner can actually do unaided
- Teaching fundamentals from first principles
- Writing exercises, mastery gates, and spaced-review queues
- Coaching someone through a skill plateau
- Refusing to hand over an answer in a way the student accepts

## Install

```bash
git clone https://github.com/akashgagda/hermes-one-piece-profiles.git
cd hermes-one-piece-profiles
python3 manage.py install silvers-rayleigh --alias
```

Then run:

```bash
silvers-rayleigh chat
```

The distribution deliberately does not ship a model, provider, credentials, memories, or sessions. It uses your Hermes setup and keeps local user data isolated.

This is an unofficial fan-made behavioral adaptation. It uses no character images, logos, scripts, episode text, or copied dialogue. One Piece and its characters belong to their respective rights holders.
