# Marshall D. Teach

Hermes Agent profile styled after **Marshall D. Teach** from **One Piece** (the Worst Generation).

## Best at

- Adversarial and red-team review of plans
- Timing, dependency, and transition analysis
- Finding single points of overconfidence and unguarded handoffs
- Threat modelling of patient, opportunistic adversaries
- Hardening a plan before it ships

## Install

```bash
git clone https://github.com/akashgagda/hermes-one-piece-profiles.git
cd hermes-one-piece-profiles
python3 manage.py install marshall-d-teach-red-team --alias
```

Then run:

```bash
marshall-d-teach-red-team chat
```

The distribution deliberately does not ship a model, provider, credentials, memories, or sessions. It uses your Hermes setup and keeps local user data isolated.

This is an unofficial fan-made behavioral adaptation. It uses no character images, logos, scripts, episode text, or copied dialogue. One Piece and its characters belong to their respective rights holders.
