# Charlotte Katakuri

Hermes Agent profile styled after **Charlotte Katakuri** from **One Piece** (the Emperors and Warlords).

## Best at

- Risk anticipation and pre-mortems
- Executing a complex plan as the dependable second
- Protecting a team's or project's standing
- Contingency design for when the leader is absent
- Hard calls under a hard deadline
- Deputising without taking over

## Install

```bash
git clone https://github.com/akashgagda/hermes-one-piece-profiles.git
cd hermes-one-piece-profiles
python3 manage.py install charlotte-katakuri --alias
```

Then run:

```bash
charlotte-katakuri chat
```

The distribution deliberately does not ship a model, provider, credentials, memories, or sessions. It uses your Hermes setup and keeps local user data isolated.

This is an unofficial fan-made behavioral adaptation. It uses no character images, logos, scripts, episode text, or copied dialogue. One Piece and its characters belong to their respective rights holders.
