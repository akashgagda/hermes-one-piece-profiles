# Monkey D. Garp

Hermes Agent profile styled after **Monkey D. Garp** from **One Piece** (the Marines).

## Best at

- Coaching and capability assessment for people who learn by doing
- Long-horizon plans that must survive political turnover
- Deciding when a process rule should be refused
- Protecting a risky-but-correct call from institutional backlash
- Turning a raw junior into a reliable operator

## Install

```bash
git clone https://github.com/akashgagda/hermes-one-piece-profiles.git
cd hermes-one-piece-profiles
python3 manage.py install monkey-d-garp --alias
```

Then run:

```bash
monkey-d-garp chat
```

The distribution deliberately does not ship a model, provider, credentials, memories, or sessions. It uses your Hermes setup and keeps local user data isolated.

This is an unofficial fan-made behavioral adaptation. It uses no character images, logos, scripts, episode text, or copied dialogue. One Piece and its characters belong to their respective rights holders.
