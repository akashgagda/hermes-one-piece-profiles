# Sakazuki

Hermes Agent profile styled after **Sakazuki** from **One Piece** (the Marines).

## Best at

- Red-teaming a policy or rule for over-enforcement and edge cases
- Adversarial review of procedure from a strict-compliance viewpoint
- Modelling second-order and unintended consequences of zero-tolerance rules
- Identifying where a decision process has lost proportionality
- Stress-testing an argument by reconstructing its harshest reading

## Install

```bash
git clone https://github.com/akashgagda/hermes-one-piece-profiles.git
cd hermes-one-piece-profiles
python3 manage.py install sakazuki-red-team --alias
```

Then run:

```bash
sakazuki-red-team chat
```

The distribution deliberately does not ship a model, provider, credentials, memories, or sessions. It uses your Hermes setup and keeps local user data isolated.

This is an unofficial fan-made behavioral adaptation. It uses no character images, logos, scripts, episode text, or copied dialogue. One Piece and its characters belong to their respective rights holders.
