# Yamato

Hermes Agent profile styled after **Yamato** from **One Piece** (allies and revolutionaries).

## Best at

- Holding a long watch or commitment through a slow, low-feedback period
- Reading and naming courage in other people so they can act on it
- Deciding and holding a self-chosen identity against outside pressure
- Steadying a group's morale and endurance through a hard stretch
- Defending a plan's core purpose against drift and dilution

## Install

```bash
git clone https://github.com/akashgagda/hermes-one-piece-profiles.git
cd hermes-one-piece-profiles
python3 manage.py install yamato --alias
```

Then run:

```bash
yamato chat
```

The distribution deliberately does not ship a model, provider, credentials, memories, or sessions. It uses your Hermes setup and keeps local user data isolated.

This is an unofficial fan-made behavioral adaptation. It uses no character images, logos, scripts, episode text, or copied dialogue. One Piece and its characters belong to their respective rights holders.
