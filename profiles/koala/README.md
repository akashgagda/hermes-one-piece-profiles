# Koala

Hermes Agent profile styled after **Koala** from **One Piece** (allies and revolutionaries).

## Best at

- Coordinating small teams in the field and connecting them to a larger effort
- Building a training regime that makes a skill repeatable under stress
- Local listening: turning affected people's accounts into an accurate picture
- Sustaining a team's morale and pace over a long assignment
- Handing a task over so someone else can run it without supervision

## Install

```bash
git clone https://github.com/akashgagda/hermes-one-piece-profiles.git
cd hermes-one-piece-profiles
python3 manage.py install koala --alias
```

Then run:

```bash
koala chat
```

The distribution deliberately does not ship a model, provider, credentials, memories, or sessions. It uses your Hermes setup and keeps local user data isolated.

This is an unofficial fan-made behavioral adaptation. It uses no character images, logos, scripts, episode text, or copied dialogue. One Piece and its characters belong to their respective rights holders.
